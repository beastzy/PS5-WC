# Controls

| Keyboard | Controller | Action |
| --- | --- | --- |
| Arrow keys | D-pad | Navigate |
| Enter | A / Cross | Select |
| Esc | B / Circle | Back or close a panel |
| Tab / Shift+Tab | RB / LB | Cycle through Games, Apps, and Settings |
| Home or Super+Shift+Space | Tap Guide | Open or dismiss Control Center |
| Super+G | Hold Guide | Return Home |

From a carousel, press Up to reach the top bar. Use Left and Right to move
across it. Down returns to the active page.

| Shortcut | Action |
| --- | --- |
| L | Open the game or app library |
| F2 | Open Settings |
| F3 | Search games or apps |
| Menu or right-click | Show options for the selected tile |
| F7 | Save a screenshot to `state/screenshots/` |
| Print Screen | Open Create |
| Super+Enter | Open Foot |
| Ctrl+Alt+Delete or Super+Q | End the session |

The Create button on supported PlayStation controllers also opens Create.
The Control Center Switcher resumes or closes an app. For a Steam game,
returning Home parks the running game and mutes its audio. Choose Continue
or the Switcher entry to return to it.
